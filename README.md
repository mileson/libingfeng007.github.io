个人博客的静态站点仓库，保存页面、文章归档和站点资源。

<a id="readme-detail-features"></a>

## ✨ 核心特性

- **静态站点入口。** 从 index.html 查阅站点内容与页面结构。
- **文章资源归档。** 文章归档、样式与静态文件随站点集中维护。

<a id="readme-detail-audience"></a>

## ✅ 适用场景

适合维护个人博客内容与样式的读者。

## 🚀 快速开始

从 [`index.html`](index.html) 查看站点入口。修改页面或资源后，检查页面内链接、图片和样式，再沿用现有静态托管方式部署。

## 🧩 模块速查

按要处理的工作选择入口，先看模块职责，再进入对应文件或目录。

| 模块入口 | 负责什么 | 什么时候看 |
| --- | --- | --- |
| [`archives/`](archives/) | 博客文章归档 | 查阅与更新文章归档 |
| [`assets/`](assets/) | 项目图片与静态素材 | 维护图片、静态文件和展示素材 |
| [`css/`](css/) | 站点样式 | 调整站点样式 |
| [`index.html`](index.html) | 静态站点入口 | 查看页面结构、内容与资源引用 |
| [`js/`](js/) | 浏览器脚本 | 维护浏览器端交互 |
